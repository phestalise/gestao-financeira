# Meu Dinheiro

Controle financeiro pessoal com IA — registre gastos em linguagem natural, acompanhe orçamento e converse com um assistente financeiro. Feito para uso pessoal, a custo zero (Vercel + Firestore + Gemini, todos no free tier).

Configuração completa (credenciais, deploy): veja [`SETUP.md`](./SETUP.md).

```bash
npm install
npm run dev
```
